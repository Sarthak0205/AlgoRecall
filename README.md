# AlgoRecall

A spaced repetition system for retaining algorithmic patterns and preparing for technical interviews.

## Features

- Email + Google Authentication
- Spaced Repetition (1/3/7/14/30/60 days)
- CSV Import from Notion
- Dashboard Analytics
- Edit/Delete Problems
- Mobile Responsive
- Supabase RLS Security

## Tech Stack

- React
- TypeScript
- Vite
- TailwindCSS
- Supabase
- PostgreSQL
- TanStack Router
- Zod
